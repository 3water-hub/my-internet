# 财务报表分析网站

输入企业名称 → 自动搜索 A 股上市公司 → 展示近 5 年财务报表 → 解读净利润涨跌原因 → 关联同期公告事件。

## 快速开始

**方式一：直接双击 `index.html`**（推荐，零安装）
- 在文件管理器中双击 `index.html`，用浏览器打开即可。
- 纯静态前端，所有数据通过 JSONP 从东方财富公开接口获取，无需后端、无需 API Key。

**方式二：用本地静态服务器**（更稳定，避免个别浏览器对 `file://` 的限制）
- VS Code：安装 "Live Server" 扩展 → 右键 `index.html` → "Open with Live Server"。
- 或任意静态服务器（如 `python -m http.server`）托管本目录后访问。
- Windows 且无 Node/Python：在 PowerShell 中运行 `powershell -ExecutionPolicy Bypass -File .\serve.ps1`，脚本会打印实际监听地址（默认 http://localhost:8765/；若该端口被占用会自动顺延到 8766、8767…），用浏览器打开该地址即可。可用 `-Port` 参数指定起始端口，如 `.\serve.ps1 -Port 9000`。

> 使用时需联网（数据接口与 ECharts 图表库均通过 CDN/在线接口加载）。

## 功能

- **公司搜索**：输入名称或代码，自动补全（仅 A 股）。
- **概览**：营收/净利润趋势、盈利能力（毛利率/净利率/ROE）、费用结构、近 6 年主要指标表。
- **三大报表**：利润表 / 资产负债表 / 现金流量表（近 6 年年报）。
- **涨跌分析**：
  - 净利润变动**归因分解**（营收增长 / 毛利率变动 / 销售·管理·财务费用 / 税金及附加 / 所得税 / 其他残差），强制对账 Σ=ΔNP。
  - 金融业自动切换**简版归因**（无毛利率/营业成本拆分）。
  - 用接口自带 `*_RATIO` 同比字段做**交叉校验**。
  - 自动生成**中文叙事**解读。
  - 报告期 ±120 天**公告事件时间线**，按类别高亮（业绩预告/分红/重大事项/高管变动）。
- **自检模式**：在 URL 后加 `?selftest=1`，对贵州茅台跑全流程并在控制台打印对账误差。

## 数据来源

全部来自东方财富公开接口（免 Key，JSONP 跨域）：

| 用途 | 接口 |
|---|---|
| 公司搜索 | `searchapi.eastmoney.com/api/suggest/get` |
| 主要指标 | `datacenter.eastmoney.com/...` `reportName=RPT_LICO_FN_CPD` |
| 利润表 | 同上 `RPT_DMSK_FN_INCOME` |
| 资产负债表 | `RPT_DMSK_FN_BALANCE` |
| 现金流量表 | `RPT_DMSK_FN_CASHFLOW` |
| 公告/事件 | `np-anotice-stock.eastmoney.com/api/security/ann` |

## 已知限制

- **金融业**（银行/保险/证券）：财务报表结构特殊，毛利率/营业成本/销售费用字段为空，归因自动走简版。
- **季度数据为累计数**：归因仅对年报做（同口径最稳）；季报仅展示趋势。
- **退市/停牌/未披露**：字段可能为空，表格以 `—` 显示，归因将缺失项并入残差。
- **归因残差**：营业外收支、投资收益、减值损失、研发费用等未单独列示项归入"其他"，占比偏大时会提示解释力有限。
- 事件仅按时间关联展示，**不构成因果判断**。

## 降级方案

- 某接口超时/失败：对应 Tab 显示"数据加载失败 [重试]"，不影响其它 Tab。
- ECharts CDN 加载失败：图表区提示，核心数据仍由表格呈现。
- `file://` 下若被浏览器跨域策略拦截：改用 Live Server / 本地静态服务器打开。
